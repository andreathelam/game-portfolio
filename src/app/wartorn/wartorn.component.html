OVERVIEW

As the sole UI/UX Designer on Wartorn, I was responsible for building the game’s interface from the ground up. This included designing an intuitive menu system and establishing the visual direction for all UI elements. My work shaped the player experience from early wireframes through to the final game, which has successfully launched into Early Access on Steam.

Setting the Foundation


UX Flows

To better understand interactions within the game’s UI, I created two types of flows:

  • Screen flow to map how all menus connect and define possible navigation paths.
  • Action flow to break down the specific actions players can take on each screen.

Wireframes

Using Figma, I built wireframes to establish layout and content hierarchy. Since Wartorn was planned as a cross-platform title, I also accounted for gamepad controls. My focus was on creating clean, intuitive menus that prioritized essential information, while offering tooltips or pop-ups for players who wanted more detail.

With these wireframes, I collaborated closely with the creative director and engineers to ensure the designs balanced player experience with technical feasibility.

UI Design System

The UI style system I put together defined the typography, colors, textures, and elements such as frames, buttons, and tooltips.
